# 2E Room Audit and Rules Specification

## 1. Executive Summary & Component Count Verification

### Primary Source Reconciliation

- **Primary Source:** Official 2nd Edition Rulebook (`Betrayal at House on the Hill 2nd edition Rulebook.pdf`, page 3 "Game Components"):
  - **44 room tiles**
  - **1 Entrance Hall/Foyer/Grand Staircase tile** (physical tile comprising 3 connected starting rooms)
- **Engine Representation:** The physical starting tile is modeled as 3 logical records (`tile.entrance_hall`, `tile.foyer`, `tile.grand_staircase`).
- **Starting Pre-placed Tiles:**
  1. `tile.entrance_hall` (Ground)
  2. `tile.foyer` (Ground)
  3. `tile.grand_staircase` (Ground)
  4. `tile.upper_landing` (Upper - one of the 44 room tiles)
  5. `tile.basement_landing` (Basement - one of the 44 room tiles)
     **Total pre-placed logical records: 5**.
- **Drawable Room Deck:** 44 physical room tiles minus the 2 pre-placed landings (`tile.upper_landing`, `tile.basement_landing`) = **42 drawable room records**.
- **Total Logical Room Records:** 5 pre-placed + 42 drawable = **47 logical records**.

### Discrepancies Between Sources

1. **Official Base-2E Omissions in Legacy JSON (`game-data.json`):**
   - `tile.collapsed_room` (Collapsed Room): Present in official 2E component list, rulebook sidebar page 7, and image assets (`collapsed-room.jpg`). Omitted from legacy `game-data.json`. **Retained**.
   - `tile.mystic_elevator` (Mystic Elevator): Present in official 2E component list, rulebook sidebar pages 7-8, and image assets (`mystic-elevator.jpg`). Omitted from legacy `game-data.json`. **Retained**.
2. **Expansion Content Excluded:**
   - `panic-room` (Panic Room): Present in legacy asset directory (`panic-room.jpg`), but from the "Widow's Walk" expansion, not base 2E. **Excluded**.
3. **Current-Only Fabricated Rules (Unsupported by 2E Rulebook / Tile Images):**
   - `tile.operating_laboratory`: Legacy JSON had no text. Current `content/tiles.json` fabricated Knowledge roll (4+ -> +1 Knowledge). **Removed to neutral**.
   - `tile.research_laboratory`: Legacy JSON had no text. Current `content/tiles.json` fabricated Knowledge roll (4+ -> +1 Knowledge). **Removed to neutral**.
   - `tile.gardens`: Legacy JSON had no text. Current `content/tiles.json` fabricated Might gain (+1 Might once per explorer). **Removed to neutral**.
4. **Mechanical Errors in Existing Implementation:**
   - `tile.chasm`: Crossing failure previously deducted 1 Speed. Official 2E rule (rulebook page 7) states failure ends movement without trait loss.
   - `tile.graveyard`: Exit failure previously deducted 1 Sanity. Tile image and 2E rule state failure loses 1 Knowledge.
   - `tile.junk_room`: Exit failure previously deducted 1 Speed on entry rather than exit.
   - `tile.the_vault`: Opening previously gave +1 Knowledge. Verified from tile image (`vault.jpg`): interior shows two bull-skull item symbols, granting 2 Item cards, not Knowledge.
   - `tile.gallery`: Legacy `game-data.json` transcribed "bedroom"; tile image clearly reads: "fall to the Ballroom if it's in the house. If you do, take 1 die of physical damage."
   - `tile.coal_chute`: Previously modeled as an effect or graph edge; rulebook page 7 dictates mandatory entry movement immediately to Basement Landing costing 1 space of movement total.

### Symbol Distribution & Legitimate No-Symbol Rooms

The official 42 drawable room deck contains:

- **13 Omen rooms**: Abandoned Room, Balcony, Catacombs, Charred Room, Dining Room, Furnace Room, Gallery, Gymnasium, Junk Room, Kitchen, Master Bedroom, Pentagram Chamber, Servants' Quarters. (Exactly matches the 13 omen rooms on the official 2E Haunt Matrix).
- **4 Item rooms**: Storeroom, Wine Cellar, Bloody Room, Larder.
- **18 Event rooms**: Operating Laboratory, Research Laboratory, Underground Lake, Bedroom, Gardens, Ballroom, Patio, Conservatory, Organ Room, Statuary Corridor, Game Room, Tower, Chapel, Library, Attic, Graveyard, Crypt, The Vault.
- **7 Drawable No-Card rooms**:
  1. `tile.stairs_from_basement` (Stairs from Basement): Pure static two-way connection linking to the Foyer.
  2. `tile.coal_chute` (Coal Chute): Pure forced movement slide to Basement Landing.
  3. `tile.creaky_hallway` (Creaky Hallway): Neutral transition hallway with 4 doors.
  4. `tile.dusty_hallway` (Dusty Hallway): Neutral transition hallway with 4 doors.
  5. `tile.chasm` (Chasm): Barrier obstacle room requiring Speed 3+ roll to cross.
  6. `tile.collapsed_room` (Collapsed Room): Disaster room requiring Speed 5+ roll or falling to Basement.
  7. `tile.mystic_elevator` (Mystic Elevator): Dynamic multi-floor transport room rolling 2 dice on entry.
- **5 Pre-placed Starting rooms (No Card)**: Entrance Hall, Foyer, Grand Staircase, Upper Landing, Basement Landing.
